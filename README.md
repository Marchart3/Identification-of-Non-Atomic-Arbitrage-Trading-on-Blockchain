## 🛠️ 安装与运行

### 先决条件
- Git
- Python 3.x (如果是Python项目)

### 步骤

1. **克隆代码**
   ```bash
   git clone https://github.com/Marchart3/Identification-of-Non-Atomic-Arbitrage-Trading-on-Blockchain.git
   cd my-awesome-project
   ```

2. **创建虚拟环境 (推荐)**
   ```bash
   # Windows Git Bash
   python -m venv venv
   source venv/Scripts/activate
   ```

3. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

4. **运行程序**
   ```bash
   python src/main.py
   ```
